### ShortLink — Smart URL Shortener with Analysis

A modern web-based URL shortening system that converts long URLs into short, easy-to-share links and provides analytics to monitor link performance. The system supports user authentication, custom aliases, link management, fast redirection, and visual click analysis.

## Features

🔗 URL Shortening — Convert long URLs into compact short links.

✨ Custom Aliases — Create meaningful and memorable short URLs.

👤 User Authentication — Login and account-based link management.

📊 Analytics Dashboard — Track total clicks and link activity.

🌍 Geographic Analysis — View top countries associated with link visits.

🔎 Referrer Analysis — Identify where visitors are coming from.

📈 Clicks Over Time — Visualize link activity using charts.

📋 Link Management — View and manage created short links from one dashboard.

⚡ Fast Redirection — Redirect users quickly to the original destination.

🔐 Secure & Reliable — Designed with secure link handling and reliable routing.

## Project Objective

The main objective of ShortLink is to provide a simple and efficient alternative to sharing long, complex URLs while adding useful analytics capabilities. It helps users create manageable links and understand how those links are being accessed.

## System Workflow

User enters a long destination URL.

The system validates the URL.

A unique short code or custom alias is generated.

The short URL is stored with its original destination.

When the short URL is opened, the system records the visit and redirects the user.

Analytics data is displayed through the dashboard.

## Main Modules

1. Home Page

Provides the primary URL-shortening interface where users can enter a long URL and generate a short link.

2. Authentication

Provides login and account access for users who want to manage their links and analytics.

3. Dashboard

Allows authenticated users to create new links, specify optional custom aliases, view existing links, copy short URLs, and access analytics.

4. Analytics

Displays link performance through total clicks, clicks over time, top countries, and referrer information.
